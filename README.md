# CSV to HTML Table Converter

## Description

This project is a simple, static web application that converts a CSV file into an HTML table. It fetches the CSV data from a specified URL, parses it, and dynamically generates an HTML table to display the data in a user-friendly format. The application is designed to be responsive and mobile-friendly, ensuring a consistent experience across different devices.

## Features

- **CSV to HTML Conversion:** Converts CSV data into a readable HTML table.
- **Dynamic Table Generation:** Dynamically creates the table structure based on the CSV data.
- **Responsive Design:** Adapts to different screen sizes for optimal viewing on desktops, tablets, and mobile devices.
- **Error Handling:** Includes basic error handling to gracefully display error messages if the CSV data cannot be fetched or processed.
- **Clean and Modern Design:** Features a visually appealing design with a modern color scheme.

## How to Use

1.  Open the `index.html` file in your web browser.
2.  The application will automatically fetch the CSV data from the provided URL (`https://sanat-garg.github.io/calendigy-3/assets/csv-file-1760631198070.b64`) and display it as an HTML table.
3.  If there are any issues fetching or processing the CSV data, an error message will be displayed in the table area.

## Technologies Used

-   **HTML:** For the structure and content of the web page.
-   **CSS:** For styling the web page and ensuring a responsive design.
-   **JavaScript:** For fetching the CSV data, parsing it, and dynamically generating the HTML table.  Vanilla JavaScript is used, with no external libraries.
