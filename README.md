# CSV to HTML Table Converter

## Description

This project is a simple, static web application that converts a CSV file into an HTML table. It fetches the CSV data from a specified URL, parses it, and dynamically generates an HTML table to display the data in a user-friendly format. The application is designed to be responsive and mobile-friendly, ensuring a consistent experience across different devices.

The application now also displays an image in the header.

## Features

- **CSV to HTML Conversion:** Converts CSV data into a readable HTML table.
- **Dynamic Table Generation:** Creates the HTML table dynamically based on the CSV data.
- **Responsive Design:** Ensures the table is displayed correctly on various screen sizes.
- **Error Handling:** Displays an error message if the CSV data cannot be loaded.
- **Image Header:** Displays an image in the header of the page.

## Usage

1.  Enter the URL of the CSV file in the input field.
2.  Click the "Load CSV" button.
3.  The application will fetch the CSV data and display it as an HTML table below the input field.
